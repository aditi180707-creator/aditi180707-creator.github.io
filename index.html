About

/ the short version

I'm a second-year B.Tech student in Electronics and Communication at IIIT Naya Raipur who ended up in software through projects: classifiers that spot AI-generated images, cargo scanners that flag items on their own, dashboards that turn pollution data into decisions.

Outside the code I run on design. I make posters, UI screens and social graphics. That habit shows up in my engineering: if a tool works but feels bad to use, I count it as unfinished.

Design

/ where the pixels get personality

design is half of how I build

Posters, event graphics, collage layouts and UI screens, mostly in Figma and Canva. I care about type, layout rhythm and the small details that make a screen feel intentional.

It feeds the code: Kairos started as a design idea, and the dashboards in PrithviNet were shaped for people who don't read raw data. Design here is a technical skill, because it decides whether anyone uses what you built.
